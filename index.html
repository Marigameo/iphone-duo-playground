iPhone Duo playground

The fold. Partly folded, the screen curves here and small controls are hard to tap. Keep buttons, links and fields off this line; text and images can cross it. From Apple's guidelines for iPhone Duo.

Open a website

Some sites refuse to be shown inside another page. If yours stays blank, run the playground locally or let the fit-iphone-duo skill open it in a real browser.

Page colour

Safari fills the space behind its bars with the page's background colour. It's read from the page when the browser allows; set it here when it can't be.

The page sees Device Posture and Viewport Segments, as in Safari 27.1 with both flags turned on. Fold the open device to see segments appear. Off, the APIs are absent, as in Safari by default. Works on the sample page and pages from the same origin; reloads the page.

Viewport sizes in CSS pixels, from WebKit. Where Safari draws its bars inside the screen is approximate. All in poses.json, which the skill reads too.
